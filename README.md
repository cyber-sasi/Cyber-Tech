🛡️ Cyber-Tech

Interactive Cybersecurity Learning & Awareness Platform

> **Learn. Detect. Protect.**

Cyber-Tech is a browser-based cybersecurity learning and awareness platform
designed to help users understand common cyber threats, practice basic
security concepts, and improve their cybersecurity awareness through
interactive educational tools.

## 📌 Overview

Cyber-Tech combines cybersecurity education with interactive browser-based
features to make security concepts easier to understand and practice.

The platform covers common cybersecurity threats, security awareness
scenarios, password security, hashing, URL safety concepts, quizzes,
security checklists, and a beginner-friendly cybersecurity roadmap.

The project is built entirely with **HTML, CSS, and Vanilla JavaScript**,
with no backend or external framework dependencies.


## 🎯 Project Objectives

- Make cybersecurity concepts easier for beginners to understand
- Provide interactive security-awareness activities
- Demonstrate basic client-side cybersecurity concepts
- Encourage safer password and browsing practices
- Provide a structured cybersecurity learning roadmap
- Build a practical cybersecurity-focused web project

## 🚀 Key Features

### 🔐 Cybersecurity Threat Library

Learn about common cybersecurity threats including:

- Phishing
- Malware
- Ransomware
- DDoS
- SQL Injection
- Cross-Site Scripting (XSS)
- Brute Force
- Social Engineering

Each topic provides beginner-friendly explanations and security awareness
information.

### 🛠️ Interactive Security Tools

Cyber-Tech includes safe, browser-based educational tools:

- Password Strength Checker
- Password Generator
- SHA-256 Hash Generator
- URL Safety Checker
- Security Awareness Score

These tools are designed for learning and do not perform attacks against
real systems.

### 🎣 Phishing Awareness Simulator

Users can analyze fictional phishing scenarios and learn how to identify
common warning signs such as:

- Suspicious URLs
- Urgency-based messages
- Fake login requests
- Social engineering techniques

### 🧠 Cybersecurity Quiz

An interactive quiz helps users test their understanding of basic
cybersecurity concepts.

### ✅ Security Checklist

Users can track important cybersecurity practices through an interactive
security checklist.

Checklist progress is stored locally in the browser using `localStorage`.
